# DeadlyDeathAngel Dalamud Plugins

Custom Dalamud plugin repository aggregating plugins by [DeadlyDeathAngel](https://github.com/DeadlyDeathAngel).

## Add in Dalamud

1. Open **/xlsettings** → **Experimental**
2. Under **Custom Plugin Repositories**, add:

```
https://raw.githubusercontent.com/DeadlyDeathAngel/DalamudPlugins/main/repo.json
```

3. Save, then install from the Plugin Installer (third-party / custom repo list).

## Notes

Most plugins install from GitHub Releases (`…/releases/latest/download/….zip`). Publish a release on each plugin repo for the installer download to work. Anamnesis Bridge already has releases.
